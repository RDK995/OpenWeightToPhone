Tier: Cheap (attempt 1). Routing reason: none of the four fails — self-contained new files,
a fully specified Apple API, and a total oracle (the decoder either recovers the exact
string or it does not).

Goal:
Build the **independent decoder oracle** M11's AC1 requires, plus the shared QR matrix type:
1. `src/qr/types.ts` — the `QrMatrix` type every other QR module will use.
2. `src/qr/png.ts` — render a `QrMatrix` to a PNG byte buffer.
3. `scripts/qr-decode.swift` — decode a QR from a PNG using **Apple's Vision framework**,
   printing the payload.

Why this matters: M11 AC1 says an encoded pairing URL must decode "via an **independent
decoder**". A decoder written by the same project as the encoder proves only that the two
agree. Apple's Vision framework is genuinely independent of this repository, and it is the
same decoder stack the iPhone camera uses for the human-attested scan in AC2 — so a
round-trip through it is real evidence rather than self-consistency.

**You are building only the oracle here. There is no QR encoder yet — do not write one.**

Relevant Requirements:
Milestone M11 AC1. Architecture component **C2 — QR Encoder** (`src/qr/`).

Acceptance Criteria:
- `src/qr/types.ts` exports **exactly** this shape (later tasks depend on it verbatim):
  ```ts
  export type EccLevel = "L" | "M" | "Q" | "H";
  export type QrMatrix = {
    readonly size: number;      // modules per side, excluding any quiet zone
    readonly version: number;   // QR version, 1..10
    readonly ecc: EccLevel;
    readonly modules: ReadonlyArray<ReadonlyArray<boolean>>; // row-major; true = dark
  };
  ```
- `src/qr/png.ts` exports
  `matrixToPng(matrix: QrMatrix, options?: { moduleSize?: number; quietZone?: number }): Uint8Array`
  - Defaults `moduleSize = 10`, `quietZone = 4` (4 modules is the QR-spec quiet zone; Vision
    will not reliably detect a code without it).
  - Dark modules render **black**, light modules and the quiet zone render **white**.
  - Output is a valid PNG decodable by macOS.
  - Throws if `matrix.modules` is not `size` rows of `size` booleans.
- **Reuse the repository's existing dependency-free PNG encoder** rather than writing a
  second one: `scripts/generate-icons.ts` already has `createPng` and `computeCrc32`
  (currently unexported, around lines 6 and 32). Export them, or move them into a shared
  module that both `scripts/generate-icons.ts` and `src/qr/png.ts` import. Either way
  **`bun run icons` and `test/icons.test.ts` must still behave identically** — this is a
  refactor of where that code lives, never a change to what it produces.
- `scripts/qr-decode.swift` — a Swift script run as `swift scripts/qr-decode.swift <png-path>`:
  - Uses `Vision`'s `VNDetectBarcodesRequest` restricted to `[.qr]` via `VNImageRequestHandler`.
  - On success prints **only** the decoded payload string to stdout and exits 0.
  - On no barcode found, or a missing/unreadable file, prints a diagnostic to stderr and
    exits non-zero.
  - Takes the first QR-symbology result.
