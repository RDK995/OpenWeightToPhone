1. The module exports exactly this, with these names and signatures verbatim:

```ts
import type {
  SessionCoordinator,
  SendResult,
  ResumeResult,
  GenerationHandlers,
} from "../session-coordinator";
import type { Conversation } from "../conversation-store";
import type { Profile } from "../api-client";

export interface UiActions {
  send(
    conversationId: string,
    prompt: string,
    handlers?: GenerationHandlers
  ): Promise<SendResult>;
  cancel(conversationId: string): Promise<{ status: string }>;
  chooseProfile(conversationId: string, profileId: string): Promise<Conversation>;
  resumeIfInterrupted(
    conversationId: string,
    handlers?: GenerationHandlers
  ): Promise<ResumeResult>;
  listProfiles(): Promise<Profile[]>;
  createConversation(input: { profileId: string; title?: string }): Promise<Conversation>;
}

export function createActions(coordinator: SessionCoordinator): UiActions;
```

2. **One-to-one, no bypass.** Each action makes **exactly one** call, on the coordinator
   passed to `createActions`, and nothing else:
   | action | coordinator call |
   | --- | --- |
   | `send(id, prompt, handlers)` | `coordinator.send(id, prompt, handlers)` |
   | `cancel(id)` | `coordinator.cancel(id)` |
   | `chooseProfile(id, profileId)` | `coordinator.setProfile(id, profileId)` |
   | `resumeIfInterrupted(id, handlers)` | `coordinator.resumeIfInterrupted(id, handlers)` |
   | `listProfiles()` | `coordinator.listProfiles()` |
   | `createConversation(input)` | `coordinator.createConversation(input)` |
   Arguments are forwarded unchanged and in order. The resolved value is returned
   unchanged. A rejection propagates unchanged — no swallowing, no wrapping, no retry, no
   default value. No action performs any validation, transformation, logging, or state
   mutation of its own.

   being added to `SessionCoordinator` by a concurrent task (M9-T1) and may not be on disk
   when you start. Write `web/src/ui/actions.ts` against the signatures
   `listProfiles(): Promise<Profile[]>` and

   allowed files), and do NOT cast the type away. Report it plainly under
