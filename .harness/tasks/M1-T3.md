TASK

Tier: Cheap (no reason to go above it: two small static files with an exactly stated shape)

Goal:
Create the minimal PWA shell (architecture component **C12**) that the asset server will
serve at `/app/`, plus the browser entry stub that establishes the build seam. Minimal is
the point: this milestone only proves the shell is reachable same-origin.

Relevant Requirements:
- FR2: "It is served on the same origin as the API, so requests carry no CORS requirement."
- Architecture C12 — PWA Shell: "Make the app installable and loadable — document,
  manifest, icons and service worker." Location `web/public/`.
- Milestone M1 acceptance criterion 1 requires `GET .../app/` to return `200` with
  `content-type: text/html` served from this repository's built bundle.

Acceptance Criteria:
1. `web/public/index.html` exists and is a complete, valid HTML5 document:
   - `<!doctype html>`, `<html lang="en">`, `<meta charset="utf-8">`
   - `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`
   - `<title>Phone Reasoning Surface</title>`
   - A `<main id="app">` element containing a short placeholder line of text.
   - `<script type="module" src="./main.js"></script>` — a RELATIVE src, not absolute.
     It must be relative because the app is mounted under the `/app/` path prefix and an
     absolute `/main.js` would resolve to the harness API's origin root instead.
   - A small amount of inline `<style>` is fine; do not create a separate CSS file.
2. `web/src/main.ts` exists and is a tiny stub that, on load, sets
   `document.documentElement.dataset.appShell = "ready"` and writes a short confirmation
   line into `#app` if that element is present. It must be safe to run with no network and
   no token. It must import nothing.
3. **Do NOT create** a web app manifest, icons, or a service worker. Those belong to
   milestone M10 and creating them here puts unproven files into this milestone's diff.
4. **Do NOT create** any conversation, chat, API-client, streaming or storage code. Those
   are milestones M2-M9.

Relevant Files:
- None; both files are new.

Files Allowed To Change:

- web/src/main.ts

Constraints:
- Follow existing repository patterns.
- Do not change unrelated behaviour.
- Do not introduce dependencies unless required.
- Do not weaken tests.
- No third-party scripts, fonts, stylesheets or CDN references of any kind — the phone is
  on a tailnet with no guarantee of internet access, and this page must load offline.
