Tier: Cheap (no named reason to go higher — a field addition to a data record

Goal:
Extend the persisted `PendingGeneration` record (component C8,
`web/src/conversation-store.ts`) with the partial assistant text accumulated so
far, so that a resume after a dropped connection can reconstruct the whole
answer from persisted storage alone.

Relevant Requirements:
FR7 (Resume). The architecture's `## Data` section states:

  `PendingGeneration` — `{ generationId, lastSeq, status }`. Persisted rather than
  held in memory, because iOS may terminate a backgrounded page outright; without
  this on disk a resume is impossible.

The same reasoning applies to the text received before the drop: a coordinator
constructed fresh from persisted storage has no in-memory copy of it, so without
persisting it the resumed transcript would be missing its prefix.

Acceptance Criteria:
1. The `PendingGeneration` type gains a `partialText: string` field, so it is
   `{ generationId: string; lastSeq: number; status: string; partialText: string }`.
2. `recordProgress(conversationId, pending)` persists `partialText` through the
   storage port along with the other fields, and `getConversation` /
   `loadConversations` read it back. A `ConversationStore` constructed fresh over
   the same `StoragePort` returns the persisted `partialText`. Add a test that
   proves this by constructing a second store over the same storage port and
   reading the value back.
3. Backward compatibility with already-persisted data: a stored conversation whose
   `pending` record was written before this field existed (i.e. its JSON has no
   `partialText` key) must load without throwing, with `partialText` defaulting to
   the empty string `""`. Add a test that seeds such raw JSON directly into a
   memory storage port and loads it.
4. `recordProgress(conversationId, null)` continues to clear pending exactly as
   before.
5. Every existing test in `test/web/conversation-store.test.ts` still passes. Where
   an existing test constructs a `PendingGeneration` literal, add
   `partialText: ""` to it so it type-checks — that is the only permitted edit to
   existing tests. Do not weaken or delete any existing assertion.
6. `web/src/session-coordinator.ts` currently constructs `PendingGeneration`
   literals and will no longer type-check. You are NOT allowed to change that file
   in this task. Leave it; a following task owns it. Note this in Unresolved Issues.
   Judge your work by the conversation-store test file passing, not by a
   whole-repository type-check.
