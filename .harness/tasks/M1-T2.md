Acceptance Criteria:
Create `src/host/config.ts` exporting exactly these, all pure with respect to an injected
environment object (default `process.env`) so they are testable without mutating the real
environment:

1. `export const APP_MOUNT_PATH = "/app";` — no trailing slash.
2. `export const DEFAULT_PWA_PORT = 7788;`
3. `export function resolvePwaPort(env: Record<string, string | undefined> = process.env): number`
   - Returns `DEFAULT_PWA_PORT` when `PHONE_PWA_PORT` is unset or empty.
   - Otherwise parses it as a base-10 integer. Throws an `Error` whose message contains
     `PHONE_PWA_PORT` if it is not an integer in the range 1–65535 inclusive.
4. `export function resolveBaseUrl(env = process.env): string`
   - Returns `env.OPENWEIGHT_HARNESS_BASE_URL` when set and non-empty, with any trailing
     `/` stripped.
   - Otherwise returns the literal `"https://ryans-mac-studio.tailc3648a.ts.net"`.
5. `export function resolveTokenPath(env = process.env): string`
   - Returns `env.OPENWEIGHT_HARNESS_TOKEN_FILE` when set and non-empty.
   - Otherwise `join(homedir(), ".openweight-harness", "token")` using `node:os` and
     `node:path`.
6. `export function resolveBundleRoot(env = process.env): string`
   - Returns `env.PHONE_PWA_BUNDLE_ROOT` when set and non-empty.
   - Otherwise the absolute path of `web/dist` at the repository root, derived from
     `import.meta.url` (this file lives at `src/host/config.ts`, so the repository root is
     two directories up). Do NOT depend on `process.cwd()`.
7. `export function pairingUrl(env = process.env): string`
   - Returns `` `${resolveBaseUrl(env)}${APP_MOUNT_PATH}/` `` — i.e. base URL + `/app/`.
     No token is appended here; the pairing CLI is a later milestone and is out of scope.
8. `export function readToken(env = process.env): string`
   - Resolves the path with `resolveTokenPath(env)`.
   - `statSync` the file. If `(stat.mode & 0o077) !== 0`, throw an `Error` whose message
     includes the resolved path and the octal mode, and **do not read the file contents at
     all** — the `readFileSync` call must not have happened. Order matters: stat, check,
     then read.
   - Otherwise read the file as UTF-8, `trim()` it, and return it. Throw an `Error` whose
     message includes the path if the trimmed content is empty.
   - Let a missing-file error from `statSync` propagate; do not swallow it.
