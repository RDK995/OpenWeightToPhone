TASK

Tier: Cheap (no reason to go above it: a copy-and-bundle script with an exact output
contract and a direct test oracle)

Goal:
Create `scripts/build.ts`, the build step that produces the bundle the asset server serves:
copy everything under `web/public/` into `web/dist/`, and bundle `web/src/main.ts` into
`web/dist/main.js` with `Bun.build`.

Relevant Requirements:
- Architecture technology choice: "Browser language — TypeScript bundled by `Bun.build`".
- Architecture interface C4 → C12: "The built bundle directory is C4's content root."
- Milestone M1 acceptance criterion 1 requires the HTML be "served from this repository's
  built bundle", so `web/dist` must be produced by this script rather than hand-written.

Acceptance Criteria:
1. `scripts/build.ts` exports `export async function build(options?: { root?: string }): Promise<{ outdir: string; files: string[] }>`
   and runs that build when it is the entry point (`import.meta.main`), printing the files
   written and exiting non-zero on failure.
2. `build()` must:
   - Resolve the repository root from `import.meta.url` (this file lives at
     `scripts/build.ts`, so the root is one directory up), NOT from `process.cwd()`.
   - Remove `web/dist` if it exists, then recreate it. Use `rmSync(dist,{recursive:true,force:true})`.
     **Guard this**: refuse to remove anything whose resolved path does not end in
     `web/dist`, and throw instead. Deleting the wrong directory is the one way this script
     can do real damage.
   - Recursively copy every file under `web/public/` into `web/dist/`, preserving relative
     paths and creating intermediate directories.
   - Run `Bun.build({ entrypoints: [<root>/web/src/main.ts], outdir: <root>/web/dist,
     target: "browser", format: "esm", naming: "[name].js", minify: false, sourcemap: "none" })`
     and throw an `Error` including the build logs if `result.success` is false.
   - Return the outdir and a sorted array of the relative paths written.
3. After a successful run, `web/dist/index.html` and `web/dist/main.js` both exist, and
   `web/dist/main.js` is valid JavaScript (not TypeScript).
4. The script must be safe to run repeatedly (it starts by clearing `web/dist`).
5. Do NOT add a manifest, icons or a service worker, and do NOT add any web/public content
   of your own — `web/public/index.html` and `web/src/main.ts` are owned by another task
   and must already exist. If they do not exist, return BLOCKED rather than creating them.

Also create `test/build.test.ts` using `bun:test` that imports `build` from
`../scripts/build.ts`, runs it, and asserts:
- `web/dist/index.html` exists and its text equals `web/public/index.html`'s text.
- `web/dist/main.js` exists, is non-empty, and does not contain a TypeScript-only construct
  from the source (assert it parses as JS by `new Function` on it is NOT appropriate for an
  ES module — instead assert the file exists, is non-empty, and that `Bun.build` reported
  success by the function returning without throwing).
- The returned `files` array contains `index.html` and `main.js`.
- Calling `build()` twice in a row succeeds and produces the same file list (idempotence).

Relevant Files:
