TASK

Goal:
Make the Session Coordinator (C9) mirror a cancelled generation's partial output into the
local transcript as an assistant turn marked `cancelled: true`, so the stored transcript
records it as an interrupted answer rather than silently dropping it.

Relevant Requirements:
- Edge case (`.harness/requirements.md` line 153): "A cancelled generation records partial
  output as a turn with `cancelled: true`; the transcript must reflect that rather than
  presenting it as a complete answer."
- M4 acceptance criterion: "The cancelled generation's partial output is stored locally as a
  turn marked cancelled, and that flag matches the `cancelled` field on the corresponding
  turn returned by `GET /v1/sessions/{session_id}`."

Observed live service behaviour (established by orchestrator probe against the real harness
on 2026-08-28 — this is fact, not assumption; implement to match it):
  After cancelling mid-generation, `GET /v1/sessions/{id}` returned turns:
    index 0: role "user",      content <the prompt>,        cancelled false
    index 1: role "assistant", content "I can provide you", cancelled true
  The assistant turn's content was exactly the partial text the client had accumulated from
  `content` events before the `cancelled` event arrived (17 characters, identical string).

Acceptance Criteria:
- In `send`, on the terminal path where `status === "cancelled"`, the coordinator appends an
  assistant turn to the conversation store with:
    - `role: "assistant"`
    - `content:` the accumulated partial text (the existing `text` variable)
    - `cancelled: true`
    - `createdAt:` the same `now` timestamp already used by the sibling appends
- The user turn continues to be appended exactly as now, with `cancelled: false`, on every
  terminal path. Do not change it.
- The existing `complete` path is unchanged: assistant turn with `cancelled: false`.
- The `error` path is unchanged: still no assistant turn. This task does not touch error
  behaviour.
- Turn ordering is preserved: the user turn is appended before the assistant turn.
- The assistant turn is appended on cancellation even when the partial text is empty
  (append with `content: ""`). Mirror unconditionally on the cancelled path; do not add a
  conditional on text length.
- Tests must prove the cancelled turn is appended with `cancelled: true` AND that the
  complete path still appends with `cancelled: false` — the second is what stops the change
  from being a blanket `cancelled: true`.
